# CASE BATTLE v4
Красивый мобильный интерфейс для GitHub Pages.

Есть:
- 4 кейса: 100 / 200 / 400 / 500 ◆
- дропы дешевле и дороже кейса
- инвентарь
- продажа любого скина в любой момент
- апгрейдер только на цель дороже исходного предмета
- автоматический расчёт шанса
- анимация вращения
- сохранение баланса и инвентаря в браузере

Это демо с виртуальной валютой, без реальных денег.
