# CASE BATTLE v5.1

- Стартовый баланс: 100 ◆
- Кейсы: FREE (0), 100, 200, 400, 500 ◆
- FREE-кейс выдаёт предметы стоимостью 10 ◆
- Платные кейсы дают предметы 100–1000 ◆ с разными шансами
- Все дропы попадают в инвентарь
- Любой предмет можно продать
- Апгрейдер показывает предметы из инвентаря и только цели дороже выбранного предмета
- Шанс = стоимость исходного / стоимость цели × 100
- Успех заменяет предмет целью; проигрыш сжигает исходный предмет
- Баланс и инвентарь сохраняются в браузере

Замените index.html, style.css и game.js в GitHub.
